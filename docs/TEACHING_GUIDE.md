# 教学使用指南与本校实测数据接入

这套平台最初是为了解决我们在上《近代物理实验》和《普通物理实验》“磁控条件法测电子比荷”时的一个切身痛点：学生在实体实验台上拧了两个小时旋钮、抄了四张表，算出来的单点比荷却在 $4\text{ V}$ 偏高近一倍，画出来的截止曲线既有隆起又有长尾；最后因为看不见管芯内部发生了什么，只能在报告末尾写一句“由于存在空间电荷与边缘效应等仪器误差”草草收尾。

因此，**磁截止实验室**从设计之初就不是为了取代实体实验台上的接线与调表，而是作为实体实验前后的“透视镜”和“控制变量沙盘”。

---

## 一、推荐的课堂组织方式（虚实互补三段式）

### 1. 课前预习（约 15–20 分钟 · 第一至二幕）
- **学生做什么**：在个人电脑上打开软件，旋转并剖开 `10 + 15 + 10 mm` 的三段式真空二极管，亲手接通励磁与加速回路；在理想冷电子轨迹沙盘中连续拖动磁场滑块，观察电子回旋半径如何随磁场缩减，直到在 $B = B_c$ 处与阳极内壁刚好相切。随后在第二幕完成定位板五孔位的霍尔探头标定。
- **教师可以在这里排掉的高频误区**：
  - *“保护环是不是用来挡住杂散磁场的？”* —— 第一幕的管芯剖视图能让学生直观看到：保护环与中央阳极处于同一加速电位，它修正的是圆筒两端开口处的**静电场畸变**，但由于平时不串表测它的电流，它同时也成了电子跨区改道时的“隐形分流池”。
  - *“亥姆霍兹线圈只要通电就是匀强场，为什么要测五个孔？”* —— 第二幕允许学生尝试将一组线圈反接，亲眼看到中心磁场归零、变成四极反亥姆霍兹分布的过程，并理解五孔空间均值标定（$B = 4.231\,I_M - 0.188\ \text{mT}$）的必要性。

### 2. 实体课堂对照（课中 · 第三幕）
- **学生做什么**：在实体实验台上完成接线与多电压扫场。如果实验室条件允许，强烈建议准备**第二块数字毫伏表**（或双通道电压采集卡），将平时直接连到电源正极的保护环支路（$A_2$）也串入一只 $1\text{ k}\Omega$ 取样电阻同步读数。
- **课堂讨论支点**：把学生自己测到的单点比荷漂移与第三幕的 $B_c^2\text{--}U_a$ 多电压回归直线同屏对比。让学生自己算出横轴截距 $U_0 \approx 2.18\text{ V}$，再去量一量实验台上直热式钨丝两端的加热电压（$U_f \approx 3.68\text{ V}$），“为什么单点比荷在低电压下会偏高近一倍”的谜底当场就能揭开大半。

### 3. 课后机制探究与报告生成（约 25–30 分钟 · 第四至六幕 + 14 页手账）
- **学生做什么**：切入管内微观视角。
  - 在**第四幕**做“热初速 × 灯丝压降”的 $2\times 2$ 正交消融，追踪代表电子 `#6413` 在真实梯度场与局域等势反事实场中的两条分叉轨迹，理解为什么必须同时有轴向热初速和轴向压降，才会出现截止前的跨区延迟收集；
  - 在**第五幕**引入磁场等效倾角 $\theta$，对比电子 `#3415` 在 $\theta=0^\circ$ 下连续回环 27 圈返阴极、与在 $\theta=8^\circ$ 下被角向洛伦兹力矩每圈推滑正则角动量 $P_\phi$ 而在第 4 圈越障命中阳极的过程，并通过 72 发射方位角命运轮理解高场长尾为何平缓衰减；
  - 在**第六幕**拖动端冷滑块 $\eta$ 闭合零场分流比，切换有限开口 Laplace 边缘场观察 `#4571` 在 K 端管口被反向电场拉回保护环的过程，最后阅读手账 P14 的误差预算表，带着四项尚未闭合的开放课题完成离线 HTML 实验报告导出。

## 二、机房免安装部署说明

- **零依赖分发**：在机房或学生个人 Windows 电脑上，直接分发 Releases 中的 `MagnetronLab-Windows-x64.zip`。解压后双击 `启动实验室.cmd` 即可运行，不需要管理员权限、不需要外网连接、也不需要预装 Python 或 Node.js。
- **本地存档与防丢**：学生在每一幕填写的预测、采集的数据表与思考题笔记会自动实时写入浏览器的 `localStorage`；公用机房下课前，学生可点击顶部菜单导出 `.json` 存档文件，或直接导出自包含的 `.html` 实验报告（内嵌全部 SVG 矢量图表与 MathML 公式，任何浏览器离线双击即可打开或打印成 PDF）。

## 三、如何把贵校实验室的真实数据接入本平台？

不同高校物理实验中心采购的真空二极管批次（如不同厂家的讲义管芯或理想二极管）在电极长度、钨丝直径与亥姆霍兹线圈常数上会存在差异。本平台在架构上将**实测数据层**与**C++17 物理计算内核**做了彻底解耦，教师或助教只需两步即可将软件切换为本校实验台的配套平台：

### 第一步：核定并修改管芯几何默认值

打开 [`backend/settings.py`](../backend/settings.py) 与 [`frontend/assets/measurements.json`](../frontend/assets/measurements.json)（以及导出参考 [`data/geometry_spec.json`](../data/geometry_spec.json)），按本校仪器的技术参数卡更新四项核心几何尺寸：
- `filament_radius_um`：钨丝阴极半径（单位 $\mu\text{m}$，当前为 `37.5`）
- `anode_radius_mm`：同轴阳极筒内半径（单位 $\text{mm}$，当前为 `4.55`）
- `length_mm`：三段收集圆筒总长（单位 $\text{mm}$，当前为 `35.0`）
- `central_mm`：中央测量阳极长度（单位 $\text{mm}$，当前为 `15.0`）

> **注意**：主同轴/倾角引擎（`/api/scan`、`/api/point`、`/api/trace`、`/api/particles`）会立即按新几何尺寸实时积分；第六幕的有限开口 Laplace 边缘场模块（[`backend/physics/edge_field.py`](../backend/physics/edge_field.py)）目前为保证教学对照的一致性，在 `validate()` 函数中锁定了 `37.5 μm / 4.55 mm / 35 mm / 15 mm` 四项标准尺寸校验——若贵校管芯尺寸不同，只需修改 `edge_field.py` 第 42 行的尺寸校验阈值即可放开实时 Laplace 求解。

### 第二步：替换 `measurements.json` 中的标定与扫场记录

对照 [`data/`](../data/README.md) 目录下的 CSV 字段规范，将贵校实测的：
1. **五孔（或多点）霍尔磁场标定数据**写入 `measurements.json` 的 `calibration` 字段（含 `points`、`slope_mT_per_A`、`intercept_mT`、`r_squared`）；
2. **多电压双通道（或单通道）磁截止扫场数据**按 `columns` 顺序写入 `magnetic_scan.rows`；
3. 运行内置的数据自洽性回归测试，确认格式、校验和与物理换算无误：

```bash
python -m unittest tests/backend/test_measurements.py -v
```
