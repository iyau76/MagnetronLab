# 有限开口边缘场内核

`edge_core.cpp` 与 `edge_core.dll` 原样来自团队研究目录 `决赛准备材料/前期复盘/边缘场_保护环峰值_20261115/`。运行时由相邻 `edge_field.py` 加载，仅使用独立内存缓存。

`emission_2000K.npy` 冻结该研究的32768粒子初态：`magnetron_model.emission_samples(32768, CONFIG['seed'], 2000, 37.5e-6, .035)`。文件哈希与条件存于同名JSON。其他温度按速度平方根缩放，较少粒子取相同前缀。

必须保留研究初态的浮点运算顺序。在7°、4.5 mT处，生产通用基底与研究初态虽然只相差不超过1.75e-10 m/s，长时分界轨迹中仍有89/8192粒子改变分类。独立控制实验确认场网格与DLL相同；采用冻结研究初态后，现场计算与原档各收集电流在1e-10 μA内一致。该一致性属于固定输入复现，并不代替网格或积分收敛研究。

标准几何为35 mm、中央15 mm、阳极内半径4.55 mm、灯丝半径37.5 μm。当前DLL内部保留极间位置常量，所以边缘场界面锁定这四项。解析圆柱势生产内核及其磁盘终态缓存不受此模块修改。
