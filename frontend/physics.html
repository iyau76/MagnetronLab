方程、采样与数值方法

以下内容对应教学模型和当前独立电子研究模型。所有公式使用 SI 单位计算；界面把长度、磁场与电流换成 mm、μm、mT 和 μA 显示。

1. 先明确几何与电压

圆柱坐标的 z 轴沿灯丝，r 是到灯丝轴的距离。灯丝半径为 rf，阳极内半径为 ra，有效长度为 L，中央阳极长度为 Lc。H 端位于 z=−L/2，K 端位于 z=L/2。

Ua 是阳极相对 H 端的加速电压，Uf 是 K 相对 H 的灯丝压降。e 表示电子电荷量的正值，电子带电 −e；me 是电子质量，kB 是玻尔兹曼常数。

2. 基础理想模型

阴极等电势、无限长同轴结构、均匀轴向磁场、电子零初速，不计电子之间的相互作用。教学页的 U 是阳极相对整个等电势阴极的电压。

φ(r) = U ln(r/rf) / ln(ra/rf)
Er = −U / [r ln(ra/rf)]
me dv/dt = −e(E + v × B)

电子从 r=rf、v=0 发射。能量守恒与轴向对称性给出：

½me(vr²+vθ²) = eφ(r)
mer vθ − eBr²/2 = −eBrf²/2
vθ(r) = eB(r²−rf²)/(2mer)

在临界磁场，电子恰好在阳极处达到径向转向点：r=ra、vr=0。于是：

Bc = √(8meU/e) · ra/(ra²−rf²)
e/me = 8U ra² / [Bc²(ra²−rf²)²]

在 U>0 的这个理想模型中，|B|≤Bc 时收集全部发射电流，|B|>Bc 时不收集。教学界面以相邻测量点夹住截止；点间连线不是额外的物理展宽。

轨迹由对应电场的四阶 Runge–Kutta 积分得到。高于截止时展示到第一次径向转向，方便看清“未到达阳极”；转向点不等于已经返回阴极。数值验收包括能量、角动量、零场飞行时间和独立转向半径计算。

3. 研究模型的电势与磁场

灯丝电势沿长度线性增加，三段外电极同电势：

φf(z) = Uf(z/L + ½)
φ(r,z) = φf(z) + [Ua−φf(z)] ln(r/rf)/ln(ra/rf)
Er = −[Ua−φf(z)]/[r ln(ra/rf)]
Ez = −(Uf/L)[1−ln(r/rf)/ln(ra/rf)]
B = (B sinα, 0, B cosα)

α 是磁场与管轴的夹角。电势在截断圆柱域中满足拉普拉斯方程；端面取上述解析电势，未求解真实有限电极的端部场。磁场在空间中均匀，倾斜与非均匀是不同的假设。

“去掉灯丝梯度”把整根阴极保持在原来的平均电势 Uf/2，而不是把它改为 0 V。这样 Ez=0，径向加速电压为 Ua−Uf/2，平均加速条件保持相同。该对照仍有热初速和轴向截断边界。

4. 热发射初态

发射位置沿灯丝均匀，周向角均匀。径向向外速度使用穿过表面的通量分布，切向与轴向速度分别使用正态分布：

z ∼ Uniform(−L/2, L/2)，θ ∼ Uniform(0,2π)
f(vr) = [me/(kBT)] vr exp[−mevr²/(2kBT)]，vr>0
vθ ∼ Normal(0,kBT/me)
vz ∼ Normal(0,kBT/me)

Normal 的第二个参数是方差。软件用五维扰乱 Sobol 采样，种子为 20260910；1024、4096、8192、32768 个粒子使用同一序列的前缀。提高粒子数时保留已有初态，有助于对照小变化。当前没有从温度自动推算发射源强；温度控制初速分布，源强是独立输入。

5. 从命中位置得到两路电流

零倾角时，先由初始能量和正则角动量筛出能够证明到不了任何收集电极的电子，记为“无收集贡献”。其余电子积分到首次边界或时间上限，分别记为返回灯丝、撞击中央、撞击保护环、从轴向离开、仍在飞行。六类共同覆盖全部样本。

中央命中：r=ra 且 |z|≤Lc/2
保护环命中：r=ra 且 Lc/2<|z|≤L/2
IA1 = I发射 N中央/N
IA2 = I发射 N两保护环/N
I总收集 = IA1 + IA2

上式对应均匀发射；选择端部冷却时，以各粒子的归一化发射权重代替计数。初态筛出的电子仍保留在总发射权重中，对三段收集电流的贡献为零。穿过 z=±L/2 的粒子记为轴向离开。总收集电流可能小于发射电流。三段电极同电势，所以改变中央划分长度只需按已有命中位置重新分类；加入电极电势差后需重新计算场和轨迹。

7. 实测比较与当前结论

真实数据使用主标定 B(mT)=4.230907195 I(A)−0.188066736，测量区间为0.2–1.4 A。零励磁处的负外推值不能直接视为已知背景磁场；从该点进入只允许非负场强的研究界面时从0 mT开始，原始读数仍保留在实测记录中。

模型可产生中央隆起和中央/保护环之间的重新分配。倾斜磁场还可使电子经历多次回环后延迟收集，形成高场尾部；与实验作定量比较仍需实际安装角度、热发射分布与局部磁场的独立标定。实测比较保留实际电压、两路电流和原记录身份，发射源强不自动拟合。真实零场两保护环合计约为中央的0.81倍，并非微小修正。

真实数据区的比荷活动采用中央通道、各电压自己选取的截止判据，以及细灯丝长同轴近似；四电压拟合允许截距。截止判据、磁场截距与几何改变会影响计算值。模型已知 e/m 的正向计算，不作为新的独立 e/m 测量。
